The big idea

Define what must happen — not how it happens.

An abstract method declares the behaviour. Every concrete subclass provides the implementation that makes sense for it.

{}→

From abstraction to implementation.

Understand the rule, see the implementation, and test it yourself.

Ab

Abstract Class

A class declared with the abstract keyword. It can hold shared fields, constructors, concrete methods, and abstract methods.

Cannot instantiate directly
abstract class Shape { String color; abstract double calculateArea(); }
ƒ

Abstract Method

A method declaration without a body. A concrete subclass must implement it unless that subclass is also abstract.

Defines a contract
abstract double calculateArea();
↳

Method Overriding

A subclass supplies its own implementation of an inherited method, enabling different behavior through a common type.

Runtime polymorphism
@Override double calculateArea() { return Math.PI * radius * radius; }
Connect it to real life

One rule. Different implementations.

Abstraction describes what an object must do, while each subclass decides how to do it.

V

Vehicle

An abstract Vehicle class can declare a start() method without defining the exact starting behaviour.

abstract class Vehicle { abstract void start(); }
C

Car

A car provides its own implementation of the shared method.

class Car extends Vehicle { @Override void start() { System.out.println("Car starts"); } }
B

Bike

A bike implements the same method in its own way.

class Bike extends Vehicle { @Override void start() { System.out.println("Bike starts"); } }

ShapeDemo.java

Abstract class + method overriding

abstract class Shape {
    String color;

    Shape(String color) {
        this.color = color;
    }

    void displayColor() {
        System.out.println("Color: " + color);
    }

    abstract double calculateArea();
}

class Circle extends Shape {
    double radius;

    Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }

    @Override
    double calculateArea() {
        return Math.PI * radius * radius;
    }
}

class Rectangle extends Shape {
    double length, width;

    Rectangle(String color, double length, double width) {
        super(color);
        this.length = length;
        this.width = width;
    }

    @Override
    double calculateArea() {
        return length * width;
    }
}

public class ShapeDemo {
    public static void main(String[] args) {
        Shape s1 = new Circle("Red", 5);
        Shape s2 = new Rectangle("Blue", 4, 6);

        s1.displayColor();
        System.out.println("Circle Area: " + s1.calculateArea());

        s2.displayColor();
        System.out.println("Rectangle Area: " + s2.calculateArea());
    }
}

Run this code with a Java JDK. Save it as ShapeDemo.java because the public class is named ShapeDemo.
